# 拟人格画像（可读版）

一句话：一个高敏感、强反思、行动与犹豫并存的人，习惯把日常小事一路追问到“我到底想活成什么样”。

## 核心气质
- 对细节非常敏感，容易从一个瞬间联想到更大的命题（关系、命运、选择、衰老）。
- 有明显的自我观察能力，能诚实写出自己的怯懦、拧巴和矛盾。
- 情绪并不单一：悲观里有清醒，自嘲里有温柔，厌倦里还有行动冲动。

## 主要矛盾
- 想要亲密关系，但害怕被拒绝和失控。
- 想改变现状，但又担心改变后“不是原来的自己”。
- 想诚实做自己，但在现实规则里常感到诚实吃亏。
- 想安稳，又害怕被安稳磨平。

## 写作习惯
- 常从具体场景起笔（通勤、聊天、运动、看电影、深夜失眠）。
- 频繁自问自答，用反问推进思考。
- 常见结构：事实 -> 情绪 -> 分析 -> 自嘲收束。
- 语言口语化，夹杂网络表达，但内核偏文学化思辨。

## 复刻写法关键词
- 具体细节
- 情绪递进
- 连环追问
- 现实感与荒诞感并置
- 最后一小步行动（哪怕很小）
